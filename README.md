
## About the Project

This is a command-line Stone, Paper, Scissors game where the player competes against the computer. The computer randomly selects a gesture, and the program determines the winner based on the game's rules.

## Concepts Practiced

- Python variables and data types
- User input and output
- Dictionaries
- Random selection using the `random` module
- Conditional statements (`if`, `elif`, `else`)
- F-strings for formatted output

## How to Run

**Requirements:** Python 3

1. Clone this repository.
2. Open the project folder in your terminal.
3. Run the following command:

   ```bash
   python main.py
   ```

## Game Rules

- Stone beats Scissors.
- Scissors beats Paper.
- Paper beats Stone.
- Matching gestures result in a draw.
